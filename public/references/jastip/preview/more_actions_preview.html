⚙️ Visibility Rules

Each menu item has a condition from the code:

Mark as Completed — always visible when active (!isArchived)
Reopen Trip — replaces the above when archived
Edit Trip — only when !isArchived
Delete Trip — always (destructive)
✨ Travelogue Wrapped — when tripFinished (archived OR endDate < now)
💰 Split Bills — always
Savings Goal & Badge — always
Trip Connect — always

🗂️ What Each Action Does

Mark Completed → sets isArchived: true, shows snackbar

Reopen Trip → sets isArchived: false, isReopened: true

Edit Trip → context.push('/trip/:id/edit', extra: trip)

Delete Trip → confirmDeleteTrip() dialog

Travelogue Wrapped → /trip/:id/wrapped

Split Bills → /trip/:id/split

Badge → /trip/:id/badge

Trip Connect → /trip/:id/sync

📱 FAB Context

The FAB action on TripDetailScreen changes per active tab:

Tab 0 (Summary) → Quick Add expense sheet
Tab 1 (Expenses) → Quick Add expense sheet
Tab 2 (Itinerary) → /trip/:id/itinerary/add
Tab 3 (Budget) → FAB hidden
Tab 4 (Jastip) → /trip/:id/jastip/add

FAB is also hidden when trip.isArchived.
