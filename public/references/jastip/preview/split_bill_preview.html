Feature Summary

👥 Participants
Add unlimited participants with emoji avatars. Auto-adds "Me" on first open. Tap to see individual breakdown, long-press for edit/remove options.
💸 Group Expenses
Log shared costs with a payer and custom split. Supports multi-currency: expense stored in original currency, balances auto-converted to trip base currency.
⚖️ 3 Split Modes
Equal — auto divide.
Weighted — ratio multipliers.
Exact — literal amounts (validated to sum = total).
🔁 Settlements
Greedy debt-minimization: calculates the fewest transactions needed to settle all balances. Mark each as "Paid" inline with a single tap.
🔗 Live Share
Push real-time split-bill snapshot to Supabase when expenses/participants change, so a shared link always shows the latest state.
📤 Export / Share
Share the full settlement summary as an image or live link. Accessible from the top-right share icon whenever expenses or settlements exist.
